# Loopback Mix

macOS 用のオーディオルーターです。アプリの音もマイクも、行と列の交点をクリックするだけで、好きな仮想オーディオデバイス（ライン）へ送れます。Zoom や OBS、録音アプリでは「Line 1」などを入力として選ぶだけです。

**ダウンロード:** [最新版の DMG（Releases）](../../releases/latest) ・ 使い方は https://loopbackmix.ic2.jp/

このリポジトリには、リリースノート（[Releases](../../releases)・[CHANGELOG.md](CHANGELOG.md)）と配布用の DMG だけを載せています（ソースコードは含みません）。DMG は Developer ID で署名され、Apple の公証を受けています。

## 主な機能

- 仮想オーディオデバイス「ライン」（最大 16 本、各 2〜64 チャンネル）
- アプリごとの音の取り込み（Chrome、Safari、ミュージック、Zoom など）、システム全体の音、マイクなどの入力
- 行列型のルーター。交点の LL・LR・RL・RR ボタンで左右の入れ替え・片側だけ・左右を混ぜる
- 音源・チャンネル・ペア・ライン全体の音量とミュート（列見出しの縦フェーダー）
- ヘッドフォンやスピーカーでの同時モニター、音量キーとの連動
- 起動しているアプリを自動で一覧に表示（除外リストあり）
- メニューバーに常駐、アプリの中でのアップデート

## 動作環境

- macOS 13 Ventura 以降（アプリごとの取り込みは macOS 14.2 以降で最適）
- Apple シリコン（M1 以降）/ Intel
- Developer ID 署名・Apple の公証済み
